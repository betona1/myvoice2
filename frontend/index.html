마이크 사용 안내

원격 접속 (http://) 시 마이크가 차단됩니다!

Chrome 설정 방법:

  1. 주소창에 입력: chrome://flags/#unsafely-treat-insecure-origin-as-secure
  2. 입력란에 현재 접속 주소 입력 (예: http://100.94.106.3:9090)
  3. Enabled 선택
  4. 브라우저 재시작

localhost 접속 시:

localhost에서는 별도 설정 없이 마이크가 바로 사용 가능합니다.
