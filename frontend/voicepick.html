목소리 고르기

낱말마다 가·나·다 를 잇달아 들어 보세요. 소리 파일 이름에 낱말을 그대로 박아 두었고, 목록도 서버에서 직접 읽어 옵니다 — 표시와 소리가 어긋날 수 없습니다. 회색 글씨가 실제 파일 이름입니다.

가 · 지금 쓰는 목소리 나 · 새 녹음 목소리만 본뜸 다 · 새 녹음으로 학습 + 낱말 검사
불러오는 중…
「다」 낱말은 검사를 통과한 것만 넣었습니다 후보를 여러 개 만들어 하나하나 검사합니다 — ① 뒤에 아는 소리를 붙여 받아쓰기(앞머리가 낱말과 정확히 같아야 함) ② 소리 봉우리 수 = 글자 수 ③ 음절당 길이 ④ 앞머리 잡음. 통과한 것 중 가장 매끄러운 것을 고릅니다. 학습 모델이 여덟 번 다 실패하면 원본 모델에 새 녹음을 본뜬 것으로 다시 시도합니다. 문장은 학습 모델 그대로입니다.
어긋나면 알려 주세요 회색 파일 이름과 큰 글씨가 다르면 그건 제 잘못입니다. 그대로 적어 주시면 바로 잡겠습니다.
