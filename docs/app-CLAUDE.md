# CLAUDE.md — 중국어 학습 앱 (플러터)

> 이 파일을 앱 저장소 맨 위에 `CLAUDE.md` 로 두면, 클로드가 이 약속을 따릅니다.

## 무엇을 만드나

중국어 낱말·양사·독해를 **오프라인으로** 익히는 안드로이드·iOS 앱.
자료는 서버에서 하루치씩 내려받아 기기에 두고, 그 뒤로는 network 없이 돈다.

배우는 이는 **50대 이상**이다. 글씨는 크게, 단추는 크고 적게, 말은 쉽게.

---

## 자료는 어디서 오나

```
https://myvoice.901planner.cloud/packs/index.json          목록
https://myvoice.901planner.cloud/packs/packs/<이름>.zip     하루치
```

로그인·API 키 없음. 서버는 **정적 파일만** 내어 준다. 앱이 받아서 풀고 혼자 쓴다.

- 규격: `docs/pack-api.md` (myvoice2 저장소)
- 지침: `docs/app-guide.md` (같은 곳)

**서버 코드를 고치려 들지 말 것.** 자료가 잘못됐으면 사람에게 알리고, 앱에서 임시로 가리지 마라.

## 반드시 지킬 것

### 독해 2부분은 채점하지 않는다
교안에 정답이 없다. `reading` 항목에 `answer` 가 **없다**.
골라 보게만 하고 지문과 견주도록 안내한다. **정답을 추측해 넣지 마라.**

### audio_say 를 처리한다
양사 21개는 TTS 가 글자 하나로는 성조를 못 내어 「一杯」처럼 수사를 붙여 녹음했다.

```jsonc
{ "chinese": "杯", "audio_say": "一杯" }   // 화면엔 杯, 소리는 "yì bēi"
```

`audio_say` 가 있으면 화면에 「一杯 로 들려줍니다」처럼 곁들인다. `null` 이면 그 글자만 읽은 소리.

### 음성이 없을 수 있다
`audio.m` / `audio.f` 가 `null` 일 수 있다. 한쪽만 있으면 그쪽을 쓴다. 없으면 조용히 넘어간다.

### 받은 zip 은 sha256 을 견주고 푼다
반쯤 받은 zip 을 풀면 깨진다. 다르면 버리고 다시 받는다.

### 한꺼번에 다 받지 않는다
HSK 6급만 125일치다. 고른 주차만 받게 한다. 하루치는 0.3MB 안팎.

## 갱신

```
① index.json 받기 (늘 최신)
② data_version 이 저장해 둔 것과 같으면 → 끝
③ 다르면 lesson 마다 rev 견주기
④ rev 가 달라진 하루치만 다시 받아 덮기
⑤ 새 data_version 저장
```

`rev` = 그 zip 의 sha256 앞 12자. 서버에서 자료를 고쳐도 **앱 코드는 손댈 게 없다.**

## 화면을 짤 때 — 웹판에서 되돌린 것들

같은 데서 헤매지 마라. 아래는 실제로 여러 번 고친 것이다.

- **글씨는 크게.** 「작다」는 말을 스무 번 넘게 들었다. 기본 배율을 넉넉히 잡고,
  키우고 줄이는 단추를 **눈에 띄는 자리**에 둔다. 설정 안에 묻지 마라.
- **한쪽을 키우면 다른 쪽은 줄인다.** 뜻과 예문을 같이 키우면 화면을 넘어간다.
- **자동 넘김은 시계로 하지 않는다.** 소리가 끝나고 획순이 한 바퀴 돈 **뒤에** 넘어간다.
  정해진 시간마다 넘기면 다 보기도 전에 지나간다.
- **되풀이할 때 남녀를 번갈아.** 한 목소리만 들으면 그 소리에만 귀가 든다.
- **틈을 조절하게.** 따라 읽을 참이 사람마다 다르다 (예문 사이 0.5~10초, 되풀이 3~60초).
- **아래 단추가 가려지지 않게.** 높이를 산수로 빼지 말고 남는 자리를 쓰게 한다.
- **크기는 어림잡지 말고 재라.** 비율로 맞추면 글자 수·화면 크기에 따라 매번 빗나간다.

## 코드 약속

- **주석은 한국어로.** 무엇을 하는지가 아니라 **왜 그렇게 했는지**를 적는다.
  특히 되돌린 것·함정은 반드시 남긴다. (`⚠️` 로 시작)
- 상태는 단순하게. 큰 상태관리 얼개를 먼저 들이지 말고, 필요해지면 그때 넣는다.
- 음성은 **파일 경로로** 재생한다 (`DeviceFileSource`). 메모리에 올리지 마라.
- 화면 크기·배율·간격 같은 설정은 `shared_preferences` 에 담아 다음에도 이어지게.

### 쓸 만한 패키지

| | |
|---|---|
| `http` | 내려받기 |
| `archive` | zip 풀기 |
| `path_provider` | 저장 자리 |
| `audioplayers` 또는 `just_audio` | mp3 재생 |
| `shared_preferences` | 설정·판 기억 |
| `stroke_order_animator` | 획순 애니메이션·따라쓰기 |

획순 자료는 꾸러미에 없다 — `stroke_order_animator` 가 스스로 받는다.

## 저장 자리

```
<앱문서폴더>/packs/<course>/d001/
    data.json
    audio/*.mp3
```

푼 모양이 zip 속 모양과 같다. 앱은 「하루치 폴더 하나」만 다루면 된다.

## 자료의 한계 (숨기지 말 것)

- **HSK 음성 2.3%** 가 어긋난다 (10,070개 중 225개, 낱글자가 대부분).
- **예문은 품사 묶음에만** 있다 (1,144개). HSK 급수별 낱말에는 없다.
- **낱글자 뜻**은 교재에 없는 글자를 사전에서 옮긴 것이라 문맥과 어긋날 수 있다.

앱에서 이를 감추거나 그럴듯하게 지어내지 마라. 모르면 비워 두고, 사람에게 알린다.

## 하지 말 것

- 서버에 쓰기(POST/PUT)를 시도하지 마라. 읽기 전용이다.
- 자료를 앱 안에서 고쳐 저장하지 마라. 다음 갱신에 덮인다.
- 정답이 없는 문제에 정답을 만들어 넣지 마라.
- 음성이 없는 낱말에 기기 TTS 를 몰래 끼워 넣지 마라 (성조가 틀린다). 없으면 없다고 보인다.
