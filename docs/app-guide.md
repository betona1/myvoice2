# 앱 만들기 지침

플러터로 중국어 학습 앱을 만들 때의 약속입니다.
서버는 **정적 파일만** 내어 줍니다. 앱은 받아서 풀고, 그 뒤로는 혼자 돕니다.

---

## 1. 주소

| | |
|---|---|
| 목록 | `https://myvoice.901planner.cloud/packs/index.json` |
| 하루치 | `https://myvoice.901planner.cloud/packs/packs/<이름>.zip` |
| 규격 | [`docs/pack-api.md`](pack-api.md) |

로그인·API 키가 없습니다. CORS 열려 있습니다. `index.json` 은 `no-cache`, zip 은 일주일 캐시.

## 3. 지켜야 할 것

### ⚠️ 독해 2부분은 채점하지 않는다

교안에 정답이 적혀 있지 않습니다. `reading` 에는 `answer` 가 **없습니다**.
골라 보게만 하고, 지문과 견주도록 안내하세요. 임의로 정답을 정하지 마세요.

### ⚠️ audio_say 를 반드시 처리한다

양사 21개는 TTS 가 글자 하나만으로는 성조를 못 냅니다.
그래서 「一杯」처럼 수사를 붙여 녹음했고, 실제로 읽은 말이 `audio_say` 에 적혀 있습니다.

```jsonc
{ "chinese": "杯", "audio_say": "一杯" }   // 화면엔 杯, 소리는 "yì bēi"
```

`audio_say` 가 있으면 화면에 「一杯 로 들려줍니다」처럼 곁들여 주세요.
없으면(`null`) 그 글자만 읽은 소리입니다.

### ⚠️ 음성이 없을 수 있다

`audio.m` / `audio.f` 는 `null` 일 수 있습니다. 한쪽만 있으면 그쪽을 쓰세요.

### ⚠️ 받은 zip 은 sha256 을 견주고 푼다

반쯤 받은 zip 을 풀면 깨집니다. `index.json` 의 `sha256` 과 맞을 때만 쓰세요.

### ⚠️ 한꺼번에 다 받지 않는다

HSK 6급만 125일치입니다. 고른 주차만 받게 하세요. 하루치는 0.3MB 안팎입니다.

---

## 4. 갱신

```
① index.json 받기
② data_version 이 저장해 둔 것과 같으면 → 끝
③ 다르면 lesson 마다 rev 견주기
④ rev 가 달라진 하루치만 다시 받아 덮기
⑤ 새 data_version 저장
```

`rev` 는 그 zip 의 sha256 앞 12자입니다.
서버에서 자료를 고쳐 다시 내보내면 **그 하루치의 rev 만** 바뀝니다. 앱 코드는 손댈 게 없습니다.

---

## 5. 저장 자리

```
<앱문서폴더>/packs/<course>/d001/
    data.json
    audio/*.mp3
```

내려받아 푼 모양이 zip 속 모양과 같으므로, 앱은 「하루치 폴더 하나」만 다루면 됩니다.

---

## 6. 쓸 만한 패키지

| | |
|---|---|
| `http` | 내려받기 |
| `archive` | zip 풀기 |
| `path_provider` | 저장 자리 |
| `audioplayers` / `just_audio` | mp3 재생 (`DeviceFileSource`) |
| `shared_preferences` | `data_version`·`rev` 기억 |
| `stroke_order_animator` | 획순 애니메이션·따라쓰기 |

획순 자료는 꾸러미에 없습니다 — `stroke_order_animator` 가 스스로 받아 씁니다.

---

## 7. 화면을 짤 때 (웹에서 겪은 것)

웹판을 만들며 여러 번 되돌린 것들입니다. 같은 데서 헤매지 마시라고 적어 둡니다.

- **글씨는 크게.** 「작다」는 말을 스무 번 넘게 들었습니다. 기본 배율을 넉넉히 잡고
  키우고 줄이는 단추를 눈에 띄는 자리에 두세요.
- **한쪽을 키우면 다른 쪽은 줄인다.** 뜻과 예문을 같이 키우면 화면을 넘어갑니다.
- **자동 넘김은 시계로 하지 않는다.** 소리가 끝나고 획순이 한 바퀴 돈 **뒤에** 넘어가야 합니다.
  정해진 시간마다 넘기면 다 보기도 전에 지나갑니다.
- **되풀이할 때 남녀를 번갈아.** 한 목소리만 들으면 그 소리에만 귀가 듭니다.
- **틈을 조절하게.** 따라 읽을 참이 사람마다 다릅니다 (예문 사이 0.5~10초, 되풀이 3~60초).
- **아래 단추가 가려지지 않게.** 높이를 산수로 빼지 말고 남는 자리를 쓰게 하세요.

## 8. 자료의 한계 (알고 시작하세요)

- **HSK 음성 2.3% 가 어긋납니다** (10,070개 중 225개). 낱글자가 대부분입니다.
  받아적기로 전수 검사한 결과이며, 고칠 수 있는 553개는 이미 고쳤습니다.
- **예문은 품사 묶음에만** 있습니다 (1,144개). HSK 급수별 낱말에는 없습니다.
- **낱글자 뜻**은 교재에 없는 글자를 사전에서 옮긴 것이라, 문맥과 어긋날 수 있습니다.

---

## 9. 자료를 새로 내보내려면 (서버에서)

```bash
# 고친 과정만
docker exec myvoice2-prod python3 /app/finetune_data/_wordapp/export_pack.py hsk3 --per 20
# 문제 꾸러미
docker exec myvoice2-prod python3 /app/finetune_data/_wordapp/export_quiz.py
# 판 찍기 (data_version · rev)
docker exec myvoice2-prod python3 /app/finetune_data/_wordapp/export_stamp.py
```

`--per 30` 으로 하루 분량을, `--wav` 로 원본 음질을 고를 수 있습니다(12배 커집니다).
